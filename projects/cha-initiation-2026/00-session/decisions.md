# Project Decisions — 霸王茶姬 Initiation

## 2026-08-08 — 项目启动

### 选 霸王茶姬 的理由
- **上市时间合适** (2025-04-17 NASDAQ, 已 1.5 年), 招股书 + 10-K 公开
- **故事完整** (新茶饮赛道 + 出海 + 单店模型), 有头部机构 (招股书 5+ 家投行背书)
- **可比充足** (蜜雪冰城 / 茶百道 / 古茗 / 奈雪), 对标清晰
- **数据可得** (SEC EDGAR 全公开, 无数据源障碍)

### 跟 港股 IPO 标的的差异
- US-listed, 用 10-K / 10-Q 而非 HK 年报
- 数据以 USD 计价, 但业务以 RMB 为主 (注意换算)
- 估值锚用美股可比 (如 Luckin Coffee) + 港股茶饮可比
- 管理层披露标准不同 (US GAAP vs HK IFRS, 差异需在 02 标注)

- 跑分卡 6 份 (01-06 各一)
