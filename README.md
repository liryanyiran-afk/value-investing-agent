# Value Investing Agent

> 价值投资 agent — 面向头部金融机构买方研报标准的投研工作流
> 数据范围: A 股 + 港股通港股

## 仓库结构
- `agents/` — 6 个子 agent 规格
- `prompts/` — 各 agent 的 prompt 版本
- `outputs/` — 真实跑出来的样本 (脱敏)
- `eval/` — 评分体系 & 跑分记录
- `design-system/` — 视觉规范
- `decisions/` — 架构决策记录 (ADR)
- `docs/` — 工作流、数据源、onboarding
