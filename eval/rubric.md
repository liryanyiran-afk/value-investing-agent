# Eval Rubric — 评分维度 (v0.1)

> 头部金融机构买方研报标准。每项 1-10, 加权汇总得总分。

## 通用维度 (所有 agent 共用, 权重随 agent 变)

### 1. 准确性 (Accuracy) — 权重 30%
- 数据 100% 准确, 0 错漏
- 数字与原文一致, 单位 / 期间标注清楚
- 来源 (source ref) 可点开追溯
- 财务表勾稽关系对 (资产=负债+权益)

### 2. 完整性 (Completeness) — 权重 20%
- 该有的都有, 关键项无缺失
- 财务三表完整, 业务覆盖完整
- 风险点全列, 无漏

### 3. 深度 (Depth) — 权重 20%
- 不是套话, 有真分析
- 一阶 / 二阶思维区分
- 历史 / 行业 / 竞争 / 管理层 都有判断

### 4. 可读性 (Readability) — 权重 10%
- 段落结构清晰
- 标题 / 小标题 一目了然
- 数据可视化 (chart / 表) 充分

### 5. 视觉 (Visual) — 权重 10% (writer 之后)
- 配色专业, 不花哨
- 字体一致
- KPI 卡 / 财务表 / 图表 排版整齐
- 跨平台 (macOS / Windows) 一致

### 6. 实用性 (Actionability) — 权重 10%
- 投资建议清晰 (BUY/HOLD/SELL + 目标价)
- 风险 / 监控指标 可执行
- 蓝军自攻击到位

## Agent 特化维度

### data-collector
- 召回率: 公开数据源覆盖完整度
- 时效: 数据延迟 (T+0 / T+1)
- 结构化: 输出 JSON 是否能被下游直接消费

### data-cleaner
- 表格还原度: 跨页表合并正确率
- OCR 准确率 (无边框表)
- 数据冲突识别

### analyst
- 估值算法透明度
- 错位视角证据强度
- 蓝军自攻击 ≥ 3 条
- KPI 阈值清晰度

### writer
- 模板契合度
- 套话比例 (越低越好)
- 数据 / 结论 比

### visual-designer
- 字体跨平台一致性
- 5 页结构标准
- 跨页表 / 跨页图 无错位

## 总分计算
```
总分 = Σ (维度分 × 权重) × 10
满分 100
```

## 通过线
- scaffolding 阶段: ≥ 40 即可继续
- 内部可用: ≥ 60
- 对外发 (内部 PM 投决): ≥ 75
- 对客户发 (买方客户路演): ≥ 85
- 头部机构对标: ≥ 90
