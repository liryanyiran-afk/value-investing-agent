## 1. 六步研究法 (核心框架)

```
Step 1 公司画像      (Company Overview)
   ↓
Step 2 Pipeline × 适应症 × 阶段  (Pipeline Progress)
   ↓
Step 3 行业市场      (Market Sizing)         总市场 → 适应症 → 亚组
   ↓
Step 4 头对头竞品    (Competitive Landscape)  公司/靶点/进度/差异/专利
   ↓
Step 5 rNPV 建模     (Valuation)              市占 → 峰值 → 净CF → POS → 折现
   ↓
Step 6 投资决策      (Decision Band)          三情景 + 价带 + 上行/破发概率
```


## 2. POS (成功概率) 表 — 行业基准

| 阶段 | POS 区间 | 推荐值 | 备注 |
|---|---|---|---|
| Pre-IND | 0.05-0.10 | 0.08 | 平台/早期管线 |
| I 期 | 0.12-0.20 | 0.15 | 健康人 PK/小样本 |
| II 期阳性 (POC 拿到) | 0.25-0.40 | 0.30 | 看主终点效应量 |
| III 期进行中 | 0.50-0.60 | 0.55 | 看主终点评到没 |
| **III 期阳性 topline** | 0.65-0.75 | **0.70** | 自免/肿瘤主战场 |
| **NDA 已受理** | 0.75-0.85 | **0.80** | NMPA 实际通过率 ~88% |
| 已上市 | 1.0 | 1.0 | — |

**调节因子** (叠加在基准上):
- 靶点已验证 (同靶点有同类产品上市): +0.10
- 同类失败 (同靶点有过 III 期失败): -0.15
- 差异化明确 (me-better 证据强): +0.05
- 安全性风险高 (黑框/REMS 类): -0.10
- 大适应症拥挤 (JAK1 已有 3+ 选择性产品上市): -0.10

## 3. 头对头竞品分析的"5 个必查"

1. 同靶点已上市产品的真实市场份额 (从 IMS/IQVIA 公开数据查)
2. 同适应症历史新进入者 3-5 年稳态份额
3. 专利独佔到期年 (化合物 + 用途/制剂/晶型)
4. 核心临床数据的 endpoint 完整对比 (不是只比阳性率)
5. 渠道/销售能力 (自营 vs CSO vs BD 出去)

## 4. rNPV 建模 (6 段式)

### 4.1 公式骨架

```
峰值销售  = 目标市场 × 峰值市占率
峰值净CF  = 峰值销售 × 税后利润率
各年CF    = 峰值净CF × 渗透率(年)
各年PV    = 各年CF / (1+WACC)^t
rNPV      = Σ 各年PV × POS
```

### 4.2 渗透率公式 (4 段式)

```excel
=IF(年<上市年, 0,
  IF(年<峰值年, (年-上市年+1)/(峰值年-上市年+1),
    IF(年<衰退年, 1,
      MAX(0, 1-0.2*(年-衰退年+1)))))
```

- 上市年 = 0% (产品刚启动)
- 上市→峰值: 线性爬坡 (保守可用 S 曲线, 但 rNPV 不必太精细)
- 峰值→衰退: 100% 平台
- 衰退后: 每年 -20% (专利到期/竞品挤压)

### 4.3 BD 条款的拆分法

招股书通常只给里程碑总额 + 特许权抽成, 但**只给总额不给分档** — 必须自己分档:

```
开发里程碑: 25% × POS 0.30 = 7.5%   ← I/II/III 节点
监管里程碑: 35% × POS 0.18 = 6.3%   ← NDA/获批
商业里程碑: 40% × POS 0.12 = 4.8%   ← 首销/销售门槛
合计期望达成率: 18.6%                 ← 这个值是综合 POS, 勿重复
```

**严禁**: 把"分档 POS × 总里程碑"和"综合 POS × 总里程碑"双重打折.

### 4.4 估值桥 4 件套 (必带, 缺一不可)

```
产品 rNPV
+ BD rNPV
+ 平台价值 (早期管线/技术平台)
+ 净现金
- 烧钱折现 (N 年 × 年烧钱 / 折现)
= IPO 前股权
+ IPO 净募资
= IPO 后公平股权
÷ 发行后股本
= 公平每股
```

**漏掉任何一件 → 估值系统性偏 ±10-20%**.

**烧钱折现年数**: 18A 临床期 biotech 用 2-4 年, 保守 3-4 年, 乐观 2 年.

### 4.5 税后利润率推导

```
毛利率 (小分子口服/外用):   85%
销售费用率 (自免, CSO 模式): 35%
管理+持续研发费用率:         12%
营业利润率 = 85% - 35% - 12% = 38%
税后利润率 = 38% × (1-15%) = 32.3%   ← 高新企业税率
```

**特许权使用费利润率另算**: royalty 几乎无 COGS/销售费用, **税后利润率 85%** — 远高于自营产品.

## 5. 投资决策 (Decision Band)

### 5.1 三情景定价

| 情景 | 峰值乘数 | POS 乘数 | WACC |
|---|---|---|---|
| Bear | 0.55 | 0.80 | 0.14 |
| Base | 1.00 | 1.00 | 0.12 |
| Bull | 1.55 | 1.15 | 0.10 |

**WACC 选取**: 临床阶段 biotech 常用 10-15%, Base 12%, Bear 14% (更保守反映熊市风险溢价).

### 5.2 决策价带公式

```
认购上限 (下限)  = Bear + 35% × (Base - Bear)
合理中枢         = Base
不追高下限 (上限) = Base + 35% × (Bull - Base)
```

- 0.35 是中等风险偏好 (保守 0.3, 激进 0.4)
- **发售价 ≤ 认购上限**: 建议认购
- **认购上限 < 发售价 ≤ 中枢**: 中性, 可小仓
- **中枢 < 发售价 ≤ 不追高下限**: 偏贵, 观望
- **发售价 > 不追高下限**: 不建议此价认购

### 5.3 必给的 4 个数字

1. 发售价 vs 公平价值溢价/折价 (直接给 +xx% / -xx%)
2. 上行至 Base 公平
3. 首日破发概率 (用同期 18A IPO 上市首日表现做回测, 至少 5 家样本)
4. 6 月后预期表现 (同期 18A IPO 上市 6 月后涨跌幅中位数)

### 5.4 Tail Risk (强烈建议加)

在 Bear 之外, 再加一档:
- 核心产品上市后失败 (如 RA III 期亚组不显著、AS III 期失败)
- 整个产品 rNPV 砍 70%+
- BD 期望值降到 0
- 平台价值砍到 50%

**这个情景是为了回答"最坏能跌多少", 是定价时必看的**.

## 6. 敏感性分析 (必做)

### 6.1 单因子敏感性

至少 3 变量 × 3 档:
- WACC: 10% / 12% / 14%
- POS: Base × 0.7 / Base / Base × 1.3
- 市占率: Base × 0.5 / Base / Base × 1.5

输出 9 宫格, 看 Base 公平 HKD 在每个组合下的变动幅度.

### 6.2 双向敏感性

市占率 × POS 双向: 最有信息量, 因为这两个是估值最大的不确定性来源.

### 6.3 发售价敏感性

在发售价 ±20% 区间内, 看"建议认购/中性/观望/不追"四个区间的边界 — 直接给 PM 决策表.

## 7. 报告结构模板 (5-8 页纪要)

```
1. 投资建议 (1 页)
   - 评级: 建议认购 / 中性 / 不建议
   - 目标价区间: HKD xx - yy
   - 上行空间: +xx%
   - 核心论点 (3 条)

2. 公司画像 (0.5 页)

3. 投资亮点 (1 页)
   - 临床数据差异化
   - BD 价值
   - 平台延展性

4. 行业与市场 (1 页)

5. 竞争格局 (1 页)

6. 估值 (1.5 页)
   - rNPV 价值桥
   - 三情景公平 HKD
   - 决策价带
   - 敏感性分析

7. 风险 (1 页)
   - 临床失败
   - 审批延期
   - 竞争挤压
   - BD 履约
   - 现金流
```

## 8. 常见陷阱 (行研新手易踩)

| 陷阱 | 症状 | 修正 |
|---|---|---|
| **市占率拍脑袋** | 给 LNK01004-AD 外用 7% 全球市占 | 必做 5 维 sanity check (见 §3) |
| **POS 与里程碑 POS 重复打折** | 期望达成率 18.6% 算出里程碑后, 再用 III 期 POS 折一次 | 选定一个口径, 写在公式旁边注释 |
| **烧钱折现年数过短** | 18A clinical biotech 用 2 年 | 保守 3-4 年 |
| **专利到期年搞错** | 写"2030 到期"没分美/欧/中 | 必带地区 + 专利类型 |
| **临床数据只引结论** | 写"安全性良好" | 必给具体 endpoint |
| **BD 价值只算收入** | 没考虑 BD 履约风险 | BD 方单独尽调 (管线, 融资, 推进节奏) |
| **没给可比公司锚** | 只有 rNPV 数字 | 同期 18A IPO 5 家做表 |
| **决策价带用发售价倒推** | 用发售价 + 30% 当上行空间 | 必须用三情景独立算出再交叉 |
| **没考虑汇率风险** | HKD/RMB/USD 三币种只用静态汇率 | 必做汇率 ±5% 敏感性 |
| **没把销售费率拆细** | 自营/BD/CSO 三种用同一个销费率 | 自营 35% / BD 抽成按协议 / CSO 按净销售分 |

## 9. 案例验证: 凌科药业 (2026-08-12)

研究员初稿做得好的:
- 11 张表体系完整
- 973 个公式联动, 0 错误
- POS 按资产×阶段拆分, 方向对
- 头对头 4 段 (RA/AS/AD 口服/AD 外用)
- 先声 + Bleecker 两个 BD 都讲到

研究员初稿的关键问题:
- **市占率系统性偏乐观** (最大风险):
  - LNK01001-AD 8% → 应 3-5%
  - LNK01001-RA 6% → 应 2-4%
  - LNK01001-AS 5% → 应 2-3%
  - LNK01004-AD 外用 7% → 应 1-3% (外用红海)
  - 整体砍 50% 后, Base 公平从 HKD 278 跌到 ~140-160, 发售价 150 直接倒挂
- POS 75% for AD 偏高 (基准 0.80 + 同靶点拥挤 -0.10 = 0.70 合理)
- 烧钱折现 2 年偏乐观 (应用 3-4 年)
- 没加敏感性表
- 没做同期 18A IPO 可比
- Bleecker 没单独尽调
- 没考虑 BD 双向价值 (上行 + 稀释)

**最关键的 1 句话**: **结构完整 + 工程化到位, 但市占率假设的 sanity check 是从结构到洞察的核心跨越点**.

## 10. 未来修订路径

这份 SOP 不是终稿. 下次研究同类公司时:
1. 先按这个框架做 — 结构稳定性优先
2. 再回头看哪些步骤卡壳 — 卡壳的地方就是框架该补的地方
3. 每次研究完, 沉淀 1-2 条新经验到 §8 「常见陷阱」或 §9 「案例验证」

预期 3-5 轮迭代后, 这套 SOP 会变成"我自己的研究骨架", 不再需要查文档.
